📋 Panduan Cepat 3 Langkah Supabase:
  1. Buka supabase.com dan buat proyek baru (100% Gratis).
  2. Buka menu SQL Editor di Supabase, lalu salin dan jalankan isi file supabase-schema.sql yang sudah disediakan di folder proyek ini.
  3. Buka menu Settings → API, lalu salin Project URL dan anon public key ke form di atas, lalu klik Simpan & Hubungkan Cloud.
